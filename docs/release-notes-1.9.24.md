## What's New in 1.9.24

- **No unexpected Keychain prompts:** AIQuota now checks for reusable Claude Code credentials silently. If macOS cannot grant access without interrupting you, the app falls back to its normal Claude sign-in path.
- **More reliable updates:** every Sparkle update now uses an immutable, build-specific download. Previously cached update information can no longer resolve to a differently signed archive.
